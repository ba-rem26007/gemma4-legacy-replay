- **2026-09-27 : Architecture Hybride Non-Hallucinatoire & Edge-First.** Alignement de notre positionnement pour le Writeup : l'agent associe le raisonnement d'un petit modèle ouvert (Gemma 4 E4B/12B) à des vérificateurs déterministes d'exécution (oracles réels PHP en bac à sable Docker). Ce choix garantit le respect de la vie privée (*Privacy-by-Design*, zéro fuite de code d'entreprise) et la faisabilité sur GPU grand public (RTX 4070 Ti 12 Go).
- **2026-09-28 : ChunkedLossTrainer pour QLoRA sur grand vocabulaire (262k).** L'allocation native de `ForCausalLMLoss` dans Transformers génère un tenseur complet de logits float32 de 4,3 Go qui provoque un OOM immédiat sur GPU 15 Go (Tesla T4). Le calcul différentiable par micro-chunks de 256 tokens sur les seuls tokens d'assistant (`labels != -100`) réduit le pic VRAM de la perte de 94% (< 300 Mo) sans aucune approximation mathématique.
- **2026-09-28 : Déport d'inférence Colab / ngrok pour la Condition D.** Le serveur Dedibox étant optimisé pour les conteneurs Docker PrestaShop (CPU AMD Ryzen 5, 31 Go RAM), l'inférence du modèle fine-tuné est déportée sur Google Colab GPU via un serveur FastAPI et un tunnel ngrok, éliminant la charge LLM sur les instances de test tout en conservant une exécution locale stricte des tests Playwright/PHPUnit.
