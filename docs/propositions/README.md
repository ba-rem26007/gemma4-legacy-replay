# Propositions de modification (coordination 3 IA)

Une IA qui n'est pas propriétaire d'un fichier dépose ici sa proposition : `<IA>-<sujet>.md` ou `.diff`,
avec la preuve (commande exécutée + sortie). Le propriétaire du fichier applique ou refuse, et l'indique en fin de proposition.
Voir `CLAUDE.md`, section « Travail à 3 IA ».
